# Personal Expense Tracker (Python)

This is a beginner-friendly Expense Tracker built fully in Python.  
It stores expenses in a JSON file and provides a clean command-line interface.

---

## Features
- Add expenses with category and notes  
- View all expenses  
- Summary of total spending  
- Save data permanently using JSON  
- Beginner-friendly and well-commented code
